# RÉELLEMENT LIBRE — ce qu'on publie

Le calendrier de publication du jeûne et de la prière de 30 jours de
**Metanoia City Church**, Calgary — du 1er au 30 novembre 2026.

Une page, sans compte à créer : <https://daniopdmk-code.github.io/reellement-libre/>

- `index.html` — le calendrier, jour par jour
- `v/` — les vignettes, pour reconnaître d'un coup d'œil
- `f/` — les visuels en pleine taille, ceux qu'on publie

Les textes à coller ne sont pas ici : ils sont dans le dossier
`1-COMMUNICATION` remis à l'équipe.
